# ADR-0012: Deferred to P1/P2

## Status

Accepted

## Context

Scope is bounded to about 14 weeks on a free-tier budget.

## Decision

Deferred: query decomposition, automatic contradiction detection, embedding reuse for unchanged chunks, searching old versions, shared workspaces and roles, OpenTelemetry, pg_trgm/true BM25, Docling as an offline parser comparison, graph and multimodal retrieval, MCP tools.

## Consequences

Each item is revisited after the final milestone report.
